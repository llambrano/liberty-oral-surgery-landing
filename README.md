# Liberty Oral Surgery — Wisdom Teeth Landing Page

Redesign of the wisdom teeth page at libertyoralsurgery.com for Dr. Bryan McLelland's practice (Spokane Valley, WA · Post Falls, ID).

Open `index.html` in a browser. It is a single static page with no build step; fonts load from Google Fonts.

## Contents

- `index.html` — the page (responsive; sticky Call / Book bar on phones)
- `assets/liberty-oral-surgery-logo.svg` — vector logo cut from the Liberty brand family identity file
- `assets/liberty-oral-surgery-icon.png` — square Oral Surgery icon (favicon, footer)
- `assets/dr-mclelland-consult.jpg` — hero photo

## Brand

- Brand blue `#36A9E1` (CMYK 70/15/0/0) for accents; darker `#1C6FA6` for buttons and links so white text stays readable
